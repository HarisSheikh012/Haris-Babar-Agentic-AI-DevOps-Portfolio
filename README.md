## 🛠 Local Setup

1. **Clone the repository**
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Configure Environment**
   Create a `.env.local` file:
   ```env
   VITE_GROQ_API_KEY=your_key_here
   VITE_GROQ_MODEL=openai/gpt-oss-120b
   ```
4. **Run Development Server**
   ```bash
   npm run dev
   ```
